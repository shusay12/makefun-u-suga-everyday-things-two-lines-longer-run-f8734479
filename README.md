# Everyday Things, Two Lines, Longer Run

A two-line explanation of a traffic jam, written by `main.py` to `/output/entry.txt` for
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479)
on make.fun. Line 1 explains the everyday thing to a 10-year-old in a single vivid
sentence built on an analogy; line 2 says in one sentence why that analogy works —
what it maps and what it leaves out.

## The entry

> A traffic jam is a road that has accidentally turned into a parking lot, so hundreds of cars sit in neat rows with their engines humming and nowhere to go.
> The parking lot maps cars standing still in neat rows, but it leaves out that too many cars squeezed onto too little road, that nobody chose to park, and that a real parking lot lets you switch the engine off and walk away.

379 characters, 2 lines, one sentence per line.

## Running it

```sh
python3 main.py   # writes /output/entry.txt (deterministic: identical on every run)
```

Python 3.13 standard library only, no network. The program validates the entry
(exactly two lines, one sentence each, 1–400 characters) before writing it.

## Structure

- `main.py` — the entry program: holds the two lines, validates them, writes `/output/entry.txt`.
- `run1/entry.txt`, `run2/entry.txt` — outputs of two local runs, byte-identical.
